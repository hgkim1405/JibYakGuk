# 날짜별 작업 기록

이 디렉터리는 집약국 작업의 날짜별 진행 이력입니다. 전체 미완료 목록은 [전체 TODO](../TODO-ALL.md), Phase 2의 상세 체크는 [Phase 2 TODO](../TODO-PHASE2.md)를 기준으로 관리하고, 매 작업일의 체크와 근거는 날짜 파일에 남깁니다.

## 기록 규칙

1. 작업을 시작한 날의 한국 날짜로 `YYYY-MM-DD.md` 파일을 새로 만듭니다.
2. [`_TEMPLATE.md`](_TEMPLATE.md)를 복사하고, 오늘 목표·완료 항목·근거·미완료/차단 사유·다음 작업을 기록합니다.
3. 새 날짜 파일을 만들면 아래 `기록 목록`에 날짜·한 줄 요약 링크를 추가합니다.
4. 실제 코드, 명령 결과, 공식 문서, raw 응답 등 확인 가능한 근거가 생긴 항목만 `[x]`로 표시합니다. 예정이나 추정은 `[ ]`로 둡니다.
5. 기존 날짜 파일은 다음 작업일에 다시 쓰지 않습니다. 뒤늦은 정정은 발견한 날짜의 로그에 원래 기록 날짜와 정정 이유를 적고, 원본 기록을 보존합니다.
6. 민감한 API key, 개인 건강정보, 이용이 허가되지 않은 원문은 로그에 복사하지 않습니다. 비밀을 제거한 경로·수치·근거만 적습니다.
7. Git 이력은 사용자가 정한 commit/sync 절차로 관리합니다. 문서 변경을 자동 commit/push하지 않습니다.
